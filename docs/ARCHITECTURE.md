## Gallery

The homepage is a Server Component that renders a client viewport. [CharacterGrid](../src/components/gallery/character-grid.tsx) repeats the active character list from the [character catalog](../src/data/characters.ts) (interleaved round-robin from per-series JSON files in [`src/data/characters/`](../src/data/characters), or filtered to a single series via the floating [GalleryDock](../src/components/gallery/gallery-dock.tsx) and [`src/lib/series.ts`](../src/lib/series.ts)) by taking the spiral cell index modulo the list length. The viewport uses an [adaptation of Thiings Grid](https://github.com/charlieclark/thiings-grid/blob/a1607d3cee9e6969f5f504f0c253ee94aa50bf54/lib/ThiingsGrid.tsx) with its [MIT license](../THIRD_PARTY_NOTICES.txt).

The grid seeds a centered initial 7 × 5 window on SSR so tiles and their centered `bloom` placeholders paint before hydration, then syncs the exact viewport window on mount from viewport dimensions and cell size. It maps coordinates to stable spiral indices and mounts the visible cells plus a buffer. Pointer movement updates one translated layer once per animation frame. React updates the cell window when the center crosses a cell or the viewport resizes. A shared intersection observer decodes previews through [`src/lib/image-decode.ts`](../src/lib/image-decode.ts) as tiles enter view, mounting each mascot only after decode completes and crossfading the character and caption in over its [bloom loader](../src/components/ui/image-loader.tsx) (adapted from Generative Loaders under its [MIT license](../THIRD_PARTY_NOTICES.txt)) before unmounting the loader. Failed decodes reveal the caption and retry on re-entry. Tab reaches buttons with at least half of their area visible. Arrow keys pan from the grid or a focused mascot. Reduced motion disables drag momentum and switches bloom loaders to a static state.

The local [Mascot component](../src/components/mascot/mascot.tsx) adapts the portfolio implementation and [page-mascot](https://github.com/nilbuild/page-mascot) under its [MIT license](../THIRD_PARTY_NOTICES.txt). The component accepts sprite URLs, a reaction mode and pool, hold and release expressions, and an optional reaction callback. A pointer that moves beyond the drag threshold before a hold starts pans the grid. An active hold or two-finger pinch controls the mascot until release. Reduced motion disables gaze tracking and deformation while preserving expression changes.

The homepage passes compact catalog metadata (`{ id, name, series, v }`) to `<Gallery>`, which derives versioned Cloudflare R2 WebP URLs client-side via [`src/lib/assets.ts`](../src/lib/assets.ts) (with `<link rel="preconnect">` in [`src/app/layout.tsx`](../src/app/layout.tsx)). One [shared pointer listener](../src/components/mascot/page-pointer.ts) updates the gaze of visible mascots using cached tile bounding rects (refreshed after pan/resize) to avoid per-frame layout reads. Ambient cursor-tracking direction sheets load through a concurrency-limited, `AbortSignal`-cancellable low-priority queue in [`src/lib/image-decode.ts`](../src/lib/image-decode.ts) with proximity-based staggering, while previews and boop reactions stay high priority. The grid suspends tracking while it pans. See the [gallery assets guide](GALLERY_ASSETS.md) and [R2 storage guide](R2_STORAGE.md) for request timing and cache behavior.

## Header and catalog

The [app header](../src/components/header/app-header.tsx) composes the interactive [brand logo](../src/components/header/brand-logo.tsx), [playground link](../src/components/playground/playground-link.tsx), component guide, credits, [Support links menu](../src/components/resources/resources-menu.tsx) (GitHub Repository, Buy Me a Coffee, and Upvote on AppBuildersPH), boop order, character catalog, theme switcher, and reaction sound toggle. Below 48 rem, the full-color logo and Catalog stay visible alongside the [More options popover](../src/components/header/header-options.tsx), which contains the secondary controls. Header buttons use color for press feedback, clicking or activating the navbar logo plays an in-place alternating squishy boop animation (skipped under reduced motion), and the desktop boop-order trigger reserves space for its widest label. Both the gallery and playground persist the selected boop order in `localStorage` under `aniboop-boop-order` via [useBoopOrder](../src/hooks/use-boop-order.ts) (`useSyncExternalStore`).

On the first visit to `/` in a browser tab, a pre-hydration script in [`src/app/layout.tsx`](../src/app/layout.tsx) activates [`SplashScreen`](../src/components/splash/splash-screen.tsx) before first paint unless `sessionStorage` already recorded `aniboop-splash-seen` or `prefers-reduced-motion: reduce` is active. The header logo preloads [`aniboop-logo.svg`](../public/brand/aniboop-logo.svg) so the splash sticker paints early, plays a GPU-composited double-hop squash-and-wobble animation, and FLIP-glides into the navbar logo slot while fading the themed backdrop. Clicking, tapping, or pressing Escape, Enter, or Space prevents default key activation and skips straight into a fast dock; reloading within the same tab bypasses the splash, while opening a new tab replays it.

The [character catalog](../src/components/catalog/character-catalog.tsx) decomposes into co-located components for search controls, memoized results rendering, and responsive desktop Dialog and mobile Drawer wrappers, driven by the `useCharacterCatalog` hook. The search controls use a semantic `<search>` element with accessible, autofill-compliant form identifiers, while character thumbnails provide explicit CSS dimensions and aspect-ratio reservation to eliminate layout shifts (CLS). The dialog height is constrained by the viewport and stays steady as results change. The results reserve scrollbar space on systems with classic scrollbars. The catalog groups and normalizes the data once per catalog change, applies text queries after a 150 ms pause, and cancels any pending query when the catalog closes. The [component guide](../src/components/mascot-guide/mascot-guide.tsx) provides a self-contained, downloadable Mascot component with a clean usage example.

Shared dialogs, dropdowns, popovers, and selects fade in place when their transitions are enabled. The Boop order and Appearance menus use the shared dropdown radio group, which leaves 4 px between options. Boop order gives the selected option a checkmark and uses a stronger fill for the focused option.

All modal surfaces ([CharacterCatalog](../src/components/catalog/character-catalog.tsx), [CharacterDetails](../src/components/character/character-details.tsx), [MascotGuide](../src/components/mascot-guide/mascot-guide.tsx), and [Credits](../src/components/credits/credits.tsx)) adapt responsively: rendering as centered Radix dialogs on desktop ($\ge 48\text{rem}$) and slide-up Vaul drawers with both drag-to-dismiss gestures and an explicit close button on mobile ($< 48\text{rem}$), synchronized via [useMediaQuery](../src/hooks/use-media-query.ts) (`useSyncExternalStore`). Modal and drawer bundles load lazily via `next/dynamic` (`ssr: false`) on first open while keeping triggers and global shortcuts (`Cmd+K` / `Ctrl+K`) eager; below-the-fold catalog series sections apply `content-visibility: auto` (with `contain-intrinsic-size` and a `contain` fallback) to skip off-screen layout/paint. A focus-revealed **Skip to gallery** link precedes the header, and shared UI primitives pair `ring-*` focus styles with `forced-colors` outline fallbacks and `prefers-reduced-motion` guards.

## Character details and downloads

The [character details](../src/components/character/character-details.tsx) component provides sprite sheet downloads for both directional poses and emotional reactions, alongside resolution selection between 1080 HD ([Cloudflare R2](R2_STORAGE.md)) and 504 Web, plus a quiet pinned utility footer with **Try in Playground** (`/playground?character=<id>`) and icon-only **Surprise me** (reroll via `history: "replace"`), **Favorite** (persisted in `localStorage` under `aniboop-favorites` via [useFavorites](../src/hooks/use-favorites.ts)), and **Copy link** (`/?character=<id>`) buttons. It is accessible from the dedicated corner squircle button on each grid tile (expanded to `40 × 40 px` on mobile viewports), by clicking a character in the catalog, or directly via a `/?character=<id>` deep link. [useDownload](../src/hooks/use-download.ts) validates `response.ok`, falls back to the local 504 sheet if an R2 fetch fails, defers blob URL revocation for mobile browser reliability, and tracks per-URL in-flight state to prevent duplicate downloads.

To maximize mobile rendering performance and eliminate GPU composite overhead, modal overlays use a crisp dimmed scrim (`bg-black/70`) without expensive backdrop filter blurs. Additionally, the catalog and details modal are mutually exclusive: selecting a character in the catalog closes the catalog before opening the details dialog; when opened from the catalog, a `Back to catalog` navigation button allows returning to the active catalog search without losing filter or query state. Shareable `?character=<id>` and `?series=<slug>` URL state is managed via `nuqs` (`NuqsAdapter` in [`src/app/layout.tsx`](../src/app/layout.tsx) and shared parsers in [`src/lib/search-params.ts`](../src/lib/search-params.ts)) inside `<Suspense fallback={null}>`-wrapped query sync components so `/` and `/playground` remain statically prerendered while supporting browser Back/Forward navigation and automatic invalid-value cleanup. Sprite sheet previews slice the cached 3×3 compact WebPs via CSS backgrounds after decoding through [`src/lib/image-decode.ts`](../src/lib/image-decode.ts), showing the [bloom loader](../src/components/ui/image-loader.tsx) until ready to eliminate blank frames and extra network requests.

## Mascot playground

[`/playground`](../src/app/playground/page.tsx) is a statically prerendered App Router page that renders the client-side [Playground](../src/components/playground/playground.tsx) workbench. Users can drag and drop or browse local 3 × 3 **Directions** and **Reactions** sprite sheets (PNG, WebP, JPEG, or AVIF) into [SheetDropzone](../src/components/playground/sheet-dropzone.tsx), including dropping both sheets at once to auto-fill both slots. Local files are previewed entirely in the browser via `URL.createObjectURL` (with `URL.revokeObjectURL` cleanup on replace, remove, or unmount) and passed directly into `Mascot` alongside the shared `BoopOrderSelect` (persisted via `useBoopOrder`), `ThemeSwitcher`, and `useReactionSound` controls. Users can also open the shared `CharacterCatalog` picker—or navigate directly via `/playground?character=<id>`—to load any catalog character's `1080 × 1080` sheets via `getMascotAssetUrl` (falling back to `504 × 504` when `NEXT_PUBLIC_R2_ASSETS_URL` is unset), or follow the footer link to [page-mascot](https://github.com/nilbuild/page-mascot) to create custom sheets. Uploading custom sheets or clearing the stage removes `?character` from the URL.

## Reaction audio

[Gallery](../src/components/gallery/gallery.tsx) owns the [sound hook](../src/hooks/use-reaction-sound.ts) and passes its playback callback through the grid to `Mascot.onReact`. The callback receives the expression after the reaction sheet decodes and as each frame is selected for display. Build up can emit both blink and its follow-up expression, and an interrupted sequence skips callbacks for its canceled frames. Standalone Mascot instances can supply their own callback.

The sound preference is persisted in `localStorage` under `aniboop-reaction-sounds` (defaulting to off). Enabling sound or interacting with the gallery when previously enabled creates or resumes one Web Audio context so delayed hold and pinch frames can use it. The hook synthesizes each cue on first use, caches the buffer, and plays up to three overlapping cues across the gallery. Muting stops active cues immediately. A suspended context can resume on the next gallery interaction, and frames shown while audio is unavailable remain silent.

The [presets](../src/lib/audio/reaction-sounds.ts) are keyed by the nine names in the reaction atlas. Each preset uses the parameter order of [ZzFXMicro 1.4.0](https://github.com/KilledByAPixel/ZzFX/blob/master/ZzFXMicro.js). The local [ZzFX port](../src/lib/audio/zzfx.ts) builds audio buffers using Web Audio. It has no npm dependency or audio asset requests. See the [MIT notice](../THIRD_PARTY_NOTICES.txt) and use the [ZzFX sound designer](https://killedbyapixel.github.io/ZzFX/) to audition changes.

| Expression | Sound                   |
| ---------- | ----------------------- |
| Blink      | Soft eyelid tick        |
| Heart      | Warm double pulse       |
| Sparkle    | High glint with an echo |
| Surprised  | Quick upward squeak     |
| Wink       | Two-tone chirp          |
| Bashful    | Soft falling note       |
| Sleepy     | Slow, low sigh          |
| Dizzy      | Cycling wobble          |
| Delighted  | Bright rising chime     |

## Theme

The appearance control defaults to the system color preference. The root [theme provider](../src/components/theme/theme-provider.tsx) uses `next-themes` to persist the preference and apply the correct class before the first paint. Light tokens are defined in `:root` and dark overrides live in `.dark`. Tailwind exposes both palettes through `@theme inline`. Use semantic utilities such as `bg-card`, `text-foreground`, and `border-input` across both palettes.

The [brand palette](BRAND.md#palette) defines the surface and interaction colors. The install manifest uses the light canvas color for its startup background and theme color.

## App Router status routes

Root App Router conventions handle unmatched routes, runtime errors, and route-transition loading states using shared copy from [`src/lib/brand.ts`](../src/lib/brand.ts):

- [`src/app/not-found.tsx`](../src/app/not-found.tsx) is a zero-JS Server Component that displays the centered AniBoop sticker logo with the pure-CSS splash pop, wobble, and double-hop animation from [`src/styles/splash.css`](../src/styles/splash.css) (skipped under reduced motion), a concise message, and a link back to `/`.
- [`src/app/error.tsx`](../src/app/error.tsx) is a Client Component error boundary with the same open-canvas sticker layout, logging the error, showing `error.digest` when available, and offering **Try again** (`retry ?? reset`) alongside a link back to `/`.
- [`src/app/loading.tsx`](../src/app/loading.tsx) renders a centered [bloom loader](../src/components/ui/image-loader.tsx) inside `<main aria-busy="true">` for route-transition fallbacks.

## Fonts and metadata

The root layout loads Allo Bold and the upright Latin subset of Inter Variable through `next/font/local`. Both are served from the app with `font-display: swap` and global preloading disabled. Use `font-heading font-bold` for display type, `font-sans` for interface text, and `font-mono` for technical values that benefit from a system monospace face.

Next.js adds browser icon links from the [SVG tap mark](../src/app/icon.svg), [ICO favicon](../src/app/favicon.ico) with 16, 32, and 48 px frames, and [180 px Apple touch icon](../src/app/apple-icon.png). The [manifest route](../src/app/manifest.ts) serves `/manifest.webmanifest` with 192 px and 512 px PNGs from [public/icons](../public/icons). It also declares a separate, opaque 512 px maskable icon for launchers that crop icons to a system shape.

The [static social preview](../src/app/opengraph-image.png) shows the light gallery behind the full-color logo, slogan, and a short description. Next.js uses the 1200 × 630 PNG for Open Graph and X cards. See [SEO and site discovery](SEO.md) for the production origin, crawler rules, and verification steps.

AniBoop's official hostname is `aniboop.nmrisrl.dev`. The [Vercel backup runbook](SEO.md#backup-access-on-vercel) records the status of `aniboop.vercel.app` and covers access during a parent-domain outage. [next.config.ts](../next.config.ts) sets response security headers (`X-Content-Type-Options`, `X-Frame-Options`, `Referrer-Policy`, `Permissions-Policy`, `Cross-Origin-Opener-Policy`, and frame/base/object `Content-Security-Policy`) alongside `Cache-Control` headers for `/brand/*`, `/icons/*`, and `/aniboop-watermark.svg`. The [root layout](../src/app/layout.tsx) also renders `<Analytics />` from `@vercel/analytics/next` to collect Vercel Web Analytics when deployed on Vercel with Analytics enabled (bypassed locally).
